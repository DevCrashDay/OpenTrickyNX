This file is the "What's new" block of the installed version, built into
OpenTricky.exe (the launcher shows it without a network). The release zip
also has the block alone as whatsnew.txt beside OpenTricky.exe, which the
launcher reads first: a new text needs a new zip, not a new launcher
(port/tools/fork_release.py). It is the same block that heads the release's
notes on GitHub, hidden in an HTML comment (both are kept identical when a
release is made).
Format: port/launcher/app/ot_util.h.
Replace it with the new release's block when the release notes are written.
A "draft:" line (ignored by the launcher) marks a block that is not final
yet: the release tools warn about it, and make_release.py refuses it.
